# CIS277-Assignment2-Ganesh
A user-made PacketQueue class that utilizes a user-made MemoryPool class in order to save blocks of memory. The size of the memory as well as the number of blocks are variable. The PacketQueue class uses a user-made queue and the MemoryPool class uses a user-made stack. The MemoryPool is LIFO while the PacketQueue is FIFO
